# SLRS Design System

## Important
- DO NOT change business logic
- DO NOT modify API calls, hooks, routes, validation, or state
- ONLY redesign UI/UX and styling
- Preserve all existing functionality

---

# Design Direction

SLRS should feel like:
- premium academic software
- systematic research platform
- editorial + enterprise hybrid
- calm, minimal, intelligent

Inspired by:
- Linear
- Notion
- Vercel
- modern editorial websites
- academic publishing systems

Avoid:
- generic SaaS dashboards
- colorful Tailwind UI
- heavy gradients
- glassmorphism
- playful startup aesthetics

---

# Visual Identity

## Colors
Background:
- warm ivory
- paper beige
- soft off-white

Text:
- near-black

Accent:
- deep burgundy / wine red only

Borders:
- ultra subtle neutral borders

Avoid:
- bright blue
- purple primary buttons
- emerald/green accents
- saturated colors

---

# Typography

## Serif
Use elegant serif for:
- hero headings
- major section titles
- editorial emphasis

## Sans Serif
Use clean sans-serif for:
- body text
- navigation
- forms
- tables

## Style
- large editorial headings
- uppercase micro-labels
- generous whitespace
- refined spacing rhythm
- typography-first hierarchy

---

# Components

## Cards
- flat surfaces
- minimal/no shadow
- thin borders
- subtle separation
- avoid rounded-3xl

## Buttons
Primary:
- near-black or burgundy
- ivory text
- uppercase tracking

Secondary:
- outlined
- minimal
- editorial

## Inputs
- warm off-white background
- thin neutral borders
- no blue focus ring
- elegant focus states

## Tables
- editorial table style
- spacious rows
- subtle separators
- minimal borders
- avoid dense admin-table feel

## Navigation
- restrained
- architectural
- minimal icons
- subtle active states

---

# Layout Rules

- strong spacing consistency
- large breathing room
- calm composition
- avoid clutter
- avoid excessive widgets/cards per row

Every page should feel curated and systematic.

---

# Motion

Use only:
- subtle fade
- opacity transitions
- soft hover effects

Avoid:
- bouncing
- flashy animations
- heavy motion

---

# UI Goal

The final product should feel like:

“software used by elite research institutions”

Focus on:
- credibility
- academic rigor
- systematic workflow
- premium restraint
- calm intelligence
